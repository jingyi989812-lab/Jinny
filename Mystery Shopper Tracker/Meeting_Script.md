# MS Tracking: Meeting Script

About 2 minutes. Read while showing the tracker on screen.

**1. 为什么要做这个**
首先，这个 MS Tracking 为什么要做？
因为我们内部 Audit 有一个 improvement point，就是 Mystery Shopper 的 feedback 不可以只是记录下来，而是要一路 track 到问题真正解决。
所以 QA 就设了这个 tracker，方便我们做 follow-up。

**2. 它是怎样运作的**
其实很简单，一个 Card 就代表一个 improvement point。
每一个 Card 都会跟一样的 flow：
Feedback → Action Plan → PIC → Target Date → Follow-up → Verify → Close
这样我们就可以很清楚看到，什么问题、要做什么、谁负责、几时完成，最后有没有真正改善。

**3. 上面的数字**
上面这些数字就是让我们一眼看到现在的 status。
比如有多少是 Open、Action in Progress、Monitoring、Overdue、Verified 和 Closed。
所以开 meeting 的时候，我们可以很快知道哪些还需要 follow up。

**4. 目前有什么**
目前我们有 6 个 improvement points，是从上个礼拜 meeting 来的。
1 个 Greenlane，5 个 Cheras Leisure Mall。
其中有两个其实是在同一个 theme，就是 Consultant Sales Approach。
Greenlane 是 customer 觉得知道她的 budget 之后，consultant 的态度有变化。
Cheras 是 customer 觉得 package explanation 比较 commercial。
虽然是不同 case，但是其实都是 Sales Approach 这方面需要 improve。

**5. 今天我们需要确认什么**
所以今天每一个 point，我们主要确认 3 样东西：
Action Plan、PIC，还有 Target Date。
这三个 confirm 了，我们后面就可以直接 track。

**6. 之后怎样 follow up**
Confirm 之后，就由 PIC 去执行。
每一次 meeting，我们 update 做了什么、几时做、有什么 evidence。
然后 QA 会去 check 下一次的 Mystery Shopper feedback。
如果问题没有再出现，就 Verify，然后 Close。
如果还是有一样的问题，就 Reopen，继续 Monitor。
所以我们的重点不是把 card close 掉而已，重点是问题真的有改善。

**7. 最后**
最后在 Summary tab，我们可以看到：
什么问题、我们做了什么 action，还有最后有没有 improvement。
这样以后 Audit 问的时候，我们就可以很快 show 给他们看整个 follow-up。
Okay，这个就是我们的 MS Tracking。Any questions?
